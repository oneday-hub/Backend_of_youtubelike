What is an aggregation pipeline?
An aggregation pipeline is a sequence of stages that process MongoDB 
documents to produce a result.

Think of it like a factory assembly line: every stage receives documents, 
performs a task, and passes the result to the next stage.

For example, suppose your video collection contains:
Video	Owner	Views
Video A	User 1	100
Video B	User 1	250
Video C	User 2	80
Video D	User 1	400

You want to find all videos uploaded by User 1, sort them by views, 
and calculate how many videos they uploaded.

What is mongoose-aggregate-paginate-v2?
This is a Mongoose plugin that adds pagination support for aggregation queries.

Imagine your video platform has 10,000 videos. Returning all 10,000 videos in 
one response would be inefficient. Instead, you can return 10 videos per page.

- Aggregation pipeline: determines which documents to retrieve and how to process them.
- Pagination: divides the resulting documents into pages.
- mongoose-aggregate-paginate-v2: helps paginate aggregation results and provides 
pagination metadata.

1. bcrypt
npm i bcrypt


Purpose: Hashes passwords before storing them in the database.
- Converts a password into a one-way hash.
- Helps protect passwords if the database is exposed.
- Used during signup and login.
Example: mypassword123 → a bcrypt hash.

Important: You don't decrypt a bcrypt hash; you verify a password against it using bcrypt.compare().

2. jsonwebtoken (JWT)
npm i jsonwebtoken


Purpose: Creates and verifies JSON Web Tokens (JWTs) to support authentication.

Typical flow:
1. User logs in with their credentials.
2. Server verifies the password using bcrypt.
3. Server generates a JWT.
4. Client sends the token with future requests.
5. Server verifies the token to authenticate the request.
Example:
const jwt = require("jsonwebtoken");

const token = jwt.sign(
    { userId: user._id },
    process.env.JWT_SECRET,
    { expiresIn: "1d" }
);


Keep JWT_SECRET private in your environment variables.

3. What is JWT.io?
JWT.io is a website for understanding and inspecting JSON Web Tokens.

Website: jwt.io

It helps you:
- Decode a token's header and payload.
- Understand the three parts of a JWT.
- Inspect and debug tokens.


A JWT has three parts:

Header.Payload.Signature

Security note: Decoding a JWT does not decrypt it. Its payload is usually 
readable, so never put passwords or other secrets inside it.

## Express App Configuration (`app.js`)

### 1. Create the Express application

`const app = express()`

Creates an Express application that handles HTTP requests and responses.

### 2. CORS

`app.use(cors({ origin: process.env.CORS_ORIGIN, credentials: true }))`

- `origin`: Specifies which frontend origin is allowed to access the backend.
- `credentials: true`: Allows browser requests to include credentials, such as cookies.

**Why?** To configure cross-origin communication between the frontend and backend.

### 3. JSON data

`app.use(express.json({ limit: "16kb" }))`

Parses incoming requests containing JSON data and makes the parsed data available in `req.body`.

**Why?** So the backend can read JSON sent by the frontend or API clients.

### 4. URL-encoded data

`app.use(express.urlencoded({ extended: true, limit: "16kb" }))`

Parses form data encoded as `application/x-www-form-urlencoded` and makes it available in `req.body`.

- `extended: true`: Allows parsing nested objects and arrays.
- `limit: "16kb"`: Limits the size of the request body handled by this parser.

### 5. Static files

`app.use(express.static("public"))`

Serves static files from the `public` directory, such as images, CSS, and PDFs.

**Why?** So clients can request these files directly without creating a separate route for each one.

### 6. Cookie parser

`app.use(cookieParser())`

Parses cookies from incoming HTTP requests and makes them accessible through `req.cookies`.

**Why?** To read cookies, including cookies used in authentication workflows.

### 7. Export the app

`export { app }`

Exports the configured Express application so another file, such as `index.js`, can import it and start the server using `app.listen()`.

### Important concept: Middleware order

`app.use()` registers middleware in order. Incoming requests pass through the registered middleware before reaching matching routes, unless a middleware ends the response or passes an error.

This is why you configure these middleware functions before registering your application routes.

What is Middleware? — Instagram Example
Think of middleware as a security checkpoint or processing station between a user's request and the server's response.

In Express.js, middleware is a function that gets access to the incoming request (req), the outgoing response (res), and a function called next() that passes control to the next middleware.
